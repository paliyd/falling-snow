# Сніг 1.3 для Mac

Нативна програма зі снігопадом, пухкими заметами та змітанням снігу курсором. macOS 14+, готова програма — для Apple Silicon. Вихідний код також можна зібрати на Intel Mac.

## Запуск

Відкрийте **Сніг.app**. Керуйте ефектом через **❄️ у смузі меню**. Лівий клік відкриває налаштування, правий — коротке меню з паузою та виходом. Закриття вікна налаштувань залишає снігопад активним; «Вийти» завершує програму.

У верхній частині налаштувань є **Мова / Language → Українська / English**. Вибрана мова застосовується одразу до всіх елементів інтерфейсу та зберігається після перезапуску. Інші налаштування снігу при цьому зберігаються.

## Плавність і витрата енергії

У налаштуваннях доступні **30 FPS** і **60 FPS**. Вибір частоти вимикає режим «Мінімум енергії», щоб зміна одразу застосувалася. Версія 1.3 початково вмикає 60 FPS на прохання користувача; решта налаштувань і вибрана мова зберігаються. Системний режим низького енергоспоживання обмежує плавний режим до 30 FPS.

Для економії ввімкніть **«Мінімум енергії»**:

- Анімація працює з 20 кадрами/с у мережі та 12 кадрами/с на акумуляторі або в системному режимі низького енергоспоживання. Після вимкнення перемикача діє вибрана частота — 30 або 60 кадрів/с.
- Частинок стало менше, але об’єм снігу на вікнах збережено.
- Краї вікон перевіряються раз на секунду. Під час переміщення вікна його сніг може відреагувати із затримкою до секунди.
- Геометрія заметів і градієнти кешуються, щоб не створювати їх заново кожного кадру.
- Під час сну дисплея, неактивного сеансу чи паузи таймер анімації зупиняється. Програма не перешкоджає сну екрана.

Точна витрата залежить від розміру екрана, кількості вікон та налаштувань снігу. Ще зменшити її можна, знизивши густоту, вимкнувши накопичення або призупинивши ефект. У повністю зупиненого ефекту витрата найменша.

## Сніг під час блокування

Перемикач **«Запускати сніг після блокування»** додає одноразовий запит до стандартної заставки Apple відразу після отримання події блокування. Запит робиться лише тоді, коли дисплей уже ввімкнений. Екран не утримується активним і не будиться. На час блокування сніг на робочому столі зупиняється, щоб не малювати дві сцени одночасно. Після розблокування він відновлюється, якщо його не було призупинено.

Для цього режиму програма «Сніг» має залишатися запущеною, а системна заставка «Сніг» — бути встановленою та вибраною. Події блокування залежать від версії macOS; використовується публічний API сповіщень з недокументованими системними назвами подій, без змін автентифікації чи вимоги пароля.

Кнопка **«Сніг під час блокування…»** відкриває встановлення окремої системної заставки. Файл **Сніг.saver** також наданий поруч із програмою. Після оновлення модуля повторно перевірте вибір «Сніг»: macOS може повернути стандартну заставку. Установіть заставку для поточного користувача та виберіть її в «Системні параметри → Шпалера → Екранна заставка».

Заставка працює окремо від накладення для робочого столу, коли macOS її показує на заблокованому Mac. Без перемикача негайного запуску ручне блокування може спочатку показувати стандартне тло; заставка запускається за системним таймером. Таймер звичайного запуску заставки налаштовується окремо в macOS. Для негайного запиту після блокування використовується перемикач у програмі; він не утримує дисплей увімкненим. Вона не працює на вимкненому дисплеї й не змінює вимогу пароля. Екран введення пароля та початкове розблокування FileVault контролює macOS.

Заставка читає ті самі налаштування 30/60 FPS і режиму економії, має до 250 частинок, кешоване тло й замет. Її запуск, паузу та зупинку контролює системний механізм заставок.

## Збірка та перевірка

Потрібні Apple Command Line Tools. Запустіть `./build.command` для програми, `./test.command` для симуляції. Для включення заставки в програму спочатку виконайте `build.command` у сусідній папці `SnihLockScreen`.

Готова збірка має локальний підпис і не нотаризована Apple. Мережа, запис екрана й Accessibility не використовуються. Для накопичення на вікнах програма читає лише їхню геометрію через публічний системний API.

## Виправлення 1.3

Відновлення збережених параметрів більше не записує типові значення поверх ще не прочитаних налаштувань. Вибір мови, швидкості, вітру, частоти кадрів та режиму економії зберігається після перезапуску.
