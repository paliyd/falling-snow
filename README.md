# falling-snow
English  

Fallinfsnow is a native macOS app that brings snowfall to your desktop. Snow settles along window edges, and you can brush it away with your cursor. Customize the density, speed, flake size, and wind. Features include 30/60 FPS, an energy-saving mode, and Ukrainian and English interfaces. 

Українською

Падання снігу — нативна програма для macOS, яка додає снігопад поверх робочого столу. Сніг накопичується на краях вікон, а замети можна змітати курсором. Налаштовуй густоту, швидкість, розмір сніжинок і вітер. Доступні 30/60 FPS, режим економії енергії та український і англійський інтерфейси.
